# Tiamat (JkFa)

**Engenharia de Software · Telecom · Sistemas Autônomos**

> *"Menos interfaces para operar, mais sistemas que resolvem o problema de ponta a ponta."*

Transformo processos complexos em soluções digitais autônomas, unindo infraestrutura, desenvolvimento full-stack e inteligência artificial.

### Áreas de Atuação

- **Linguagens base:** Python, TypeScript, JavaScript, Rust
- **Aplicações:** Web moderna (React, Next.js) e Desktop nativo (Tauri)
- **Dados & IA:** Automação de fluxos, extração de dados e integração de modelos generativos
- **Infraestrutura:** Ecossistema Linux, CI/CD, computação de borda (Edge) e redes

### Projetos em Destaque

| Projeto | Descrição | Tecnologia |
|---|---|---|
| [Editais Culturais](https://github.com/JkFa/editais-culturais) | Plataforma de monitoramento e curadoria automática de oportunidades culturais no Brasil | `Python` |
| [TV Livre](https://github.com/JkFa/tv-livre) | Agregador web para transmissão de canais abertos ao vivo direto no navegador | `TypeScript` |
| [Ondas](https://github.com/JkFa/ondas-podcast) | Diretório e player leve para distribuição de podcasts independentes | `JavaScript` `Python` |
| [Cofre Virtual](https://github.com/JkFa/Cofre-Virtual) | Ferramenta desktop focada em privacidade para armazenamento seguro e criptografado | `Rust` |
